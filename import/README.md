# Gin import from the bottle photos (November 2026)

45 gins from 39 producers, identified from 45 photos of the collection.
44 of them are in the import file (Kyrö Napue is left out, see below).

## How to import (after this branch is deployed)

1. Sign in to the admin area and go to **Gins → Import CSV**.
2. Choose `import/gins_for_import.csv` and click **Preview import**. Nothing is saved yet.
3. Read the preview. Check that the *Will be added* list has no gins you already have
   under a slightly different name.
4. Click **Import 44 gins**. The number is lower if some were found as duplicates.

| File | What it is |
| --- | --- |
| `source/gins.csv` | The research list: one row per gin, with photo reference, confidence and notes |
| `source/distilleries.csv` | The research list of producers (region, website, notes) |
| `prepare_gin_import.py` | Converts the research list into the importer's format (commented step by step) |
| `gins_for_import.csv` | **The file to import.** Generated by the script; don't edit by hand |

## Rebuilding the import file

If you change anything in `source/`, regenerate the import file:

```bash
python3 import/prepare_gin_import.py
```

## What the script changes

* **Names** no longer repeat the brand, because the app shows *brand + name + (edition)*.
  For example, "Tanqueray Tanqueray Rangpur" becomes "Tanqueray Rangpur".
* **Styles** are translated to the app's fixed list. For example, "Dry Gin" becomes `distilled`,
  "Flavoured (lime)" becomes `flavoured`, and "Colour-changing" becomes `other`.
* **ABV fixes**, checked on the web on 2026-11-17:
  * Junimperium Cherry Edition: **40%** (Junimperium's other cherry gins are 40%; check the bottle)
  * Citadelle No Mistake Old Tom: **46%**
  * Teerenpeli Pyy Gin: **45%** (was 44%)
  * Lubuski Gin Original: **37.5%** (was 40%; 40% is the Lubuski 7 Year Old)
* **Producer fix:** Arctic Blue is made by *Arctic Blue Beverages* (was "Arctic Brands Group").
* **Producer names match the site.** The site already has 15 distilleries (added by the
  migration `20261102_0020_starter_distilleries.py`). Six research names were changed to
  the site's names, e.g. "Hendrick's / William Grant & Sons (Girvan)" becomes
  "Hendrick's Gin Distillery", so gins are linked to them instead of creating duplicates.
* **Kyrö Napue is left out.** It was only seen in the background of two photos, and Napue
  is the old name of Kyrö Gin, which is already on the site.
* **Bottle-specific details** (Stockholms Bränneri "Batch 6", Berliner Brandstifter
  "Edition 7/2019 bottle 368/9999") are removed from the gin. Add them to the
  bottle/purchase record instead.
* All gins are imported **hidden** (`public_visible = no`), so you can add photos and
  descriptions before they appear on the public site.

## Tested

The file was run through the app's real importer and the new import page on a test
PostgreSQL database with the same migrations as the live site: 44 gins created, 0
rejected, and the gins were linked to the existing distilleries. On the live site,
expect about 25 new distilleries. Importing the same file a second time added nothing
(44 duplicates), so gins already in the catalogue are skipped.

The importer skips a gin only if brand, name **and** edition match exactly (upper/lower
case is ignored). If you already entered a gin under a slightly different name (e.g.
"Beefeater / London Dry" instead of "Beefeater / London Dry Gin"), it would be added
a second time. Check the preview list before confirming.

## Producer details

The importer can only give a new producer a name and a country. The full profiles
(country, region, website, description) of the 25 new producers come with the database
migration `apps/api/migrations/versions/20261117_0024_photo_survey_distilleries.py`,
which runs automatically on deploy. It works in either order: if the gins were imported
first, it renames those bare producers to the clean names and fills in the empty fields,
keeping anything typed in the admin area. The research behind it changed some producers:
Lubuski is now made by Henkell Freixenet Polska (Toruń), Imea by Antica Distilleria
Quaglia, Plymouth at the Black Friars Distillery and Opihr by G&J Distillers.

Three bottles were left out because their labels are only partly visible:
a Bombay "...can Juniper" 47% (IMG_5917), an Italian "M... Premium Blended Dry"
(IMG_5929) and a South African pure grape gin (IMG_5931).
